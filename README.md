# Valkyrie - 2D Platform Oyunu

Bu proje, Programlama II dersi dönem ödevi kapsamında SFML kütüphanesi kullanılarak C++ dilinde geliştirilmiştir.

## 🚀 Nasıl Çalıştırılır?
1. Proje dizininde terminali açın.
2. `make` komutu ile projeyi derleyin.
3. `./program` komutu ile oyunu başlatın.

## 🎮 Kontroller
* **A / D:** Sol - Sağ Hareket
* **W:** Zıplama
* **SPACE (Boşluk):** Kılıç Saldırısı
* **ENTER:** Oyunu Başlat
* **R:** Yeniden Başlat (Game Over/Win sonrası)

## 🛠 Kullanılan Teknolojiler
* **Dil:** C++
* **Grafik & Ses:** SFML (Simple and Fast Multimedia Library)
* **Derleme:** Makefile
